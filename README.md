# 🏥 Hospital Data Analysis Full Project

## 📌 Project Overview
This project analyzes hospital data to understand patient trends, medical expenses, and hospital performance.

The goal is to convert raw data into useful insights for better decision-making.

---

## 🎯 Business Questions
This project answers important business questions:

- How many patients are treated overall?
- Which departments have the highest demand?
- Which hospitals generate the most revenue?
- How do medical expenses vary per patient?
- Which cities have the highest patient load?
- Which departments have longer treatment duration?
- How do expenses change over time?

---

## 🛠 Tools Used
- Excel → DataTypes Formatting  
- SQL (PostgreSQL, pgAdmin) → Data analysis and Extractions
- Python (Pandas, NumPy, Matplotlib, Jupyter Notebook) → Data exploration and Cleaning,Advanced Analysis
- Power BI → Dashboard creation  

---

## 📊 Key Analysis

- Total patients and total expenses
- Patients by department and city
- Monthly medical expenses trend
- Average stay duration per department
- Expense per day analysis
- Doctors per hospital

---

## 📈 Dashboard Features

- KPI Cards (Total Patients, Total Expenses, Avg Stay,Avg Doctor Per Hospital,Total Hospitals)
- Filters (City, Hospital, Department)
- Bar charts and line charts and Others Charts
- Clean and dark theme design

---

## 💡 Key Insights

- Daily medical expenses range from **₹363 to ₹44,452**
- Average expense per day is around **₹7,200**
- Most patients fall in **₹2,000 – ₹8,000 range**
- Maximum hospital stay is **15 days**
- Some departments have higher patient demand
- Few high-cost cases increase overall revenue
- Some cities have higher patient load than others
